# 状态行追加不覆盖

来源：ensure-pi-patch 的 showStatus 补丁（marker `hapiStatusStack`）。扩展与 pi 内置提示（Switched to… 等）走同一条通道，连续通知追加显示，不互相覆盖。

## 触发

线 B。在验证终端里触发两条以上连续状态提示：切换模型（内置提示）+ 触发一个扩展通知（如 notify 类操作）。间隔要短，保证第二条出现时第一条还在展示期。

## 断言

1. `hc read` 读屏：两条提示同时可见（追加成栈），而非只剩最后一条。
2. 再触发一次内置提示：新提示入栈，旧提示按序退场，无闪烁替换痕迹。

## 盲区

- 状态行在屏上的精确位置与样式（颜色、边框）读屏文本看不到，升人工。
- pi 上游若改状态行实现，补丁锚点失配只会启动警告——Doctor 不覆盖这条，验收失败时先查启动警告。
