# slash 中段补全触发

来源：ensure-pi-patch 的中段 slash 补全触发门（含 `/` 键触发）。输入行中间位置键入 `/` 也能唤出补全菜单，而非只在行首。

## 触发

线 B。在验证终端输入行：先键入若干普通字符（如 `say`），再把光标移回行中键入 `/`。

## 断言

1. `/` 键入后补全菜单出现（`hc read` 能看到菜单渲染）。
2. 行首键入 `/` 的基线行为不回归（菜单照常出现）。
3. Esc 关闭菜单后输入行内容完整，无字符丢失。

## 盲区

菜单的出现时机与按键延迟（手感）自动断言不了；`hc read` 是节拍采样，瞬时菜单可能恰好落在两次采样之间——读不到时先用 `hc read` 连续多拍确认，仍看不到再升人工。
