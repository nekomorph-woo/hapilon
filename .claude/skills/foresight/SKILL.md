# Foresight

在做某件事之前，先了解相关知识——从互联网和项目中收集信息，结构化输出为面向初学者的文档，存入 `_foresight.md`。

## 工作流程

### 1. 归档历史

如果 `_foresight.md` 存在且有内容：

```bash
mkdir -p _foresight
N=$(ls _foresight/*.md 2>/dev/null | wc -l | tr -d ' ')
N=$((N + 1))
# 从文件首行 H1 标题提取 kebab-case 名称，若无则用主题的 kebab-case
NAME="<topic-kebab-case>"
mv _foresight.md "_foresight/${N}-${NAME}.md"
```

N 从 1 开始递增，kebab-case 名称从原 `_foresight.md` 的内容或当前主题中提取。

### 2. 收集信息

#### 2.1 互联网搜索

使用 `!python3 ...` 或 MCP WebSearch 工具搜索以下内容：

- 核心概念和术语定义
- 主流方案/工具对比
- 最佳实践和常见陷阱
- 初学者入门路线图
- 相关生态和资源

每个方向提取 2~3 个关键来源。

#### 2.2 项目内探索

使用 `/wok-kit:look` 探索项目中与此知识相关的现有内容：

- 代码库中是否已有相关实现
- `Hapilon-PRD-v1.1.md` 中是否涉及
- `_CHANGELOG-alpha.md` 中是否有相关进度
- 其他相关配置文件或文档

### 3. 结构化输出

将收集到的信息整理为以下结构，写入 `_foresight.md`：

```markdown
# <主题名>

> 一句话概括：这是什么，为什么需要了解它。

## 核心概念

<关键术语和概念，面向初学者解释>

## 主要方案/工具对比

| 方案 | 特点 | 适用场景 |
|------|------|----------|
| ... | ... | ... |

## 与本项目的关系

<这个知识在当前项目中如何落地，哪些 PRD 章节或代码涉及>

## 入门路线图

<从零开始的渐进学习步骤，面向完全不了解的人>

## 常见陷阱

<容易踩的坑和注意事项>

## 参考资源

- <链接 1>
- <链接 2>
```

语言：**中文**，保持初学者友好——避免术语堆砌，必要时给出类比。

### 4. 检查清单

- [ ] 历史文档已归档到 `_foresight/{N}-{name}.md`
- [ ] `_foresight.md` 已用新内容覆盖
- [ ] 内容结构完整（核心概念 / 方案对比 / 项目关联 / 路线图 / 陷阱）
- [ ] 语言面向初学者，无未经解释的术语
