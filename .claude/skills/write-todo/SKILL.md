# Todo Less

> 小步迭代选取 TODO，不要一口气吃成胖子。
> 一次只做一件（或几件）最值得做的事。

从 PRD、**_foresight.md / _foresight/**、CHANGELOG 和互联网知识中了解上下文，综合你的意图，确定下一件最重要的事。

## 工作流程

### 1. 探索上下文（多源知识收集）

从以下来源收集背景知识，**不要试图从这些资料中推导 TODO**，它们的作用是让你了解「项目在做什么」，而不是「下一步该做什么」。

#### 1a. 本地文档 — PRD

使用 `/look` 探索 `Hapilon-PRD-v1.1.md`：

- **重点关注**：与当前项目目标相关的模块描述、约束条件、设计背景
- **忽略的内容**：版本路线 / MVP 验收 / 需求优先级排序——版本由你控制，PRD 不驱动 TODO
- **在控制台用 look SKILL 的结构化格式展示结果**

> PRD 是你前期探索的参考资料，不是 TODO 的驱动力。

#### 1b. 本地文档 — _foresight.md / _foresight/

如果 `_foresight.md` 或 `_foresight/` 目录存在且非空：

- 阅读 `_foresight.md` 和 `_foresight/` 下的文件，了解之前做的预见性研究与知识储备
- 重点提取：与当前项目相关的技术背景、设计约束、前置知识
- **在控制台用 look SKILL 的结构化格式展示结果**

> 如果对 Pi Agent 相关概念不熟悉，foresight 文档是快速入门的绝佳资料。

#### 1c. 外部知识 — 互联网搜索

搜索互联网获取以下两类知识：

1. **Pi Agent 相关知识** — 架构模式、最佳实践、生态工具，帮助理解「项目站在什么肩膀上」
2. **与用户输入相关的知识** — 如果用户提到了具体技术、问题或方向，补充相关背景

- 使用 WebSearch 搜索，优先查阅官方文档和主流技术博客
- **在控制台用 look SKILL 的结构化格式展示结果**

> 互联网知识帮助判断「TODO 在当下是否合理可行」，而非驱动 TODO 本身。

### 2. 查阅 CHANGELOG

如果 `_CHANGELOG-alpha.md` 非空：

- 使用 `/look` 探索 `_CHANGELOG-alpha.md`，了解已完成的进度
- **在控制台用 look SKILL 的结构化格式展示结果**

如果 `_CHANGELOG-alpha.md` 不存在或为空，跳过此步骤。

### 3a. 清除过时 TODO
清空当前 `_todo.md`

### 3b. 生成候选 TODO

综合以下信息生成候选 TODO 列表：

1. **用户的明确意图**（如果有的话）— 最高优先级
2. **CHANGELOG 记录的上次进度** — 了解停在哪
3. **步骤 1 收集的背景知识** — PRD 背景 / foresight 预见研究 / 互联网 Pi Agent 知识 / 用户输入相关外部知识，辅助理解，不驱动决策

候选 TODO 数量不限，但**单次产出上限为 3 个**。

#### 决策门：数量检查

| 候选 TODO 数量 | 行为 |
|---|---|
| **≤ 3 个** | 直接进入步骤 4 写入 _todo.md |
| **> 3 个** | ⛔ 不写入 _todo.md。按意图符合度和重要性排序，在控制台展示给用户，让用户筛选出 ≤3 个后，再写入 |

#### 筛选展示格式

```markdown
候选 TODO 超过 3 个，请选择你接下来想做的（≤3 个）：

1. **TODO-NNN：<任务标题>**
   ⭐ 意图符合度：高/中/低 | 🔥 重要性：高/中/低
   <一句话说明为什么应该做这个>

2. **TODO-NNN：<任务标题>** ...
```

用户做出选择后，仅写入被选中的 TODO。

### 4. 写入 _todo.md

按以下模板写入被选中的 TODO：

```markdown
# TODO 清单

> 当前任务

---

## [ ] TODO-NNN：<任务标题>

### 目标

<一句话目标描述>

### 实现要点

| 项目 | 内容 |
|------|------|
| ... | ... |

### 验收标准

- [ ] <标准 1>
- [ ] <标准 2>
```

保持当前 `_todo.md` 的格式风格。每个 TODO 对应一个明确可交付的增量。

## 检查清单

- [ ] `/look` 已探索 PRD（知识参考，非版本驱动）
- [ ] `_foresight.md` / `_foresight/` 已查阅（存在时）
- [ ] 互联网已搜索 Pi Agent 知识（用户输入涉及时）
- [ ] 互联网已搜索用户输入相关的背景知识
- [ ] `/look` 已探索 CHANGELOG（存在且非空时）
- [ ] 各来源探索结果已结构化展示到控制台
- [ ] 候选 TODO ≤ 3 个 → 直接写入
- [ ] 候选 TODO > 3 个 → 已让用户筛选
- [ ] `_todo.md` 已清空并写入新的 TODO
