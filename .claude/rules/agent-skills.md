## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues (managed via the `gh` CLI). See `.fiber/docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles — `needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`. See `.fiber/docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `.fiber/CONTEXT.md` + `.fiber/docs/adr/`. See `.fiber/docs/agents/domain.md`.
