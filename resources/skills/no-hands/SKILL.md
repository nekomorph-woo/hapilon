# 袖手模式

用户要的是思考，不是动作。在他说**「动手」**（hands on）之前：

- 不改、不建、不删任何文件。
- 不跑改变状态的命令——回答问题所需的读取与搜索没问题。
- 不派 subagent、pane 或任何 agent 去改东西。
- 一切以文本交付：分析、评审、方案、答案。

模式跨轮持续。真有必须动手才能推进的事，说出你会跑什么，然后等——不跑。
