# domain-modeling

领域词汇表在 `.hapilon/CONTEXT.md`（入库共享；系统提示每轮内联其内容——`<domain_glossary>` 段）。本技能只做**维护动作**；被动遵循既定术语不归这里，那是常驻规则的事。

## 格式（极简，一行一术语）

```markdown
| 术语 | 一句话定义 | 首现 |
|------|-----------|------|
| 坑 | 不查必错、错了难定位的事实型陷阱 | 2026-10-24 |
```

## 动作

1. **拍板即写**：术语被澄清/拍板/冲突解决的当轮，追加一行（或更新既有行）。不攒批次、不写长文。文件不存在就带表头创建。
2. **批量提炼初版**：新项目或用户点名时，从代码标识符、文档、对话中的业务名词提炼首版词汇表，交用户过目后落盘。
3. **整理**：去重、合并同义、过时术语在行尾标 `(deprecated)` 而非删除——保留演化痕迹；定义漂移时更新该行。
4. **人手改优先**：用户直接编辑过的行视为拍板结果，不覆盖、只在冲突时指出。

## 边界

- 只放领域术语：业务方嘴里的词。不放实现细节、不放决策记录（那些归 `.hapilon/research/`）。
- 一个概念一行一个词；新词先查表，已有近义就复用。
