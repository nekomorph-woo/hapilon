# Gates — 中英文本 AI 味检查清单

交付任何方案、文档、说明、命名之前跑一遍。

判定口径（先读这个再跑 gate）：命中一次记为线索，不动；同一特征在一篇里出现
两次以上，或词级 + 句级 + 结构级同时命中，才算违例——违例改到清零，线索可
保留。判定边界：检查的是你自己的陈述，不是你引用的内容——引用、代码、坏例/
好例示范、业务方真正的术语不在检查范围。唯一的豁免：用户明确要求不按
writing_style / human-voice 处理——默认只豁免被点名的那一次输出，用户点名了
期限（n 次、本会话、全部 pane 等）则按期限执行，到期自动回到规则之下。
gates 是编辑线索，不是检测器。

---

## 词级

1. 出现了忌口黑话（赋能 / 抓手 / 闭环 / 沉淀 / 打通 / 拉齐 / 链路 / 颗粒度 / 心智 / 底层逻辑 / 打法 / 范式）？
2. 出现了自造组合词——中英混拼（「上下文装配器」）或动宾拼贴（「读写一体编排」）这种团队里没人嘴上说过的词？中文句里嵌了英文缩略词，首现又不给中文名？（出口测试对这类词会失手——工程师口头真会说——改用隔周读者测试：不加解释还懂不懂。）
3. 用了假口语开头（说实话 / 不得不说 / 有一说一）？
4. 形容词不可验证（显著 / 大幅 / 显著提升 / 明显优化），且全文没有给出可核对的事实？

## 句级

5. 名词化句式：「进行 / 完成 / 做出 + 抽象名词」（进行配置、完成校验、做出决策）？
6. 负平行句：「不是 X，而是 Y」「不仅……更是……」——且删掉后句意不受损？
7. 修辞性排比超过两项（三个及以上并列短语 / 并列小句）？互不可推的并列
   （验收标准、不变量清单、各自独立的情况）不是排比，跳过。
8. 模板开头：「随着……的不断发展」「在……的背景下」？
9. 模板连接：「值得注意的是」「需要指出的是」「总而言之」？
10. 翻译腔胶水：「通过……从而……」「在……的情况下」「被广泛认为」连用？
11. 一句话塞了三件事以上（背景 + 动作 + 意义全在一句里）？

## 结构级

12. 冒号列表轰炸——正文一半以上是 bullet，且多项其实一句话能说完？
13. 每段都强制配了小标题 / 加粗导语，结构比内容还抢眼？
14. 开场预告（「本文将介绍」「下面从三个方面展开」）而不直接开始？
15. 结尾升华（综上所述 / 未来可期 / 标志着 / 让我们拭目以待）？
16. 全文没有作者在场——没有具体例子、反例、取舍、数据来源，结论圆满得像无风险答案？
17. 结构与内容错位：两段意思相近却被硬拆成对称结构？

## 命名

18. 分类名 / 标签 / 模块名没过出口测试——团队里没人嘴上会这么说？
19. 名字回答的是「内部怎么实现」（静默降级 / 上下文装配）而不是「这是什么」（出错就跳过 / 挑相关文件读进来）？
20. 同一概念在文中出现两个叫法（同义词分裂）？
21. 标签 / 分类里只有一个成员（孤叶标签），且它明显是某条内容的剧情词？

## 英文侧（写英文时加跑这组）

22. Throat-clearing 开场（It is important to note / This guide will walk you through / Let's dive in）？
23. 空洞 claims（seamless / robust / powerful / effortlessly）而不是可观察行为（returns 429 when rate-limited）？
24. 负平行句（not just X, but Y / it's not X, it's Y）且删掉否定不失意？
25. 三连列表（rule of three）没有删到两项以内？互不可推的并列不算。
26. 填充词读着像 AI 腔（delve / tapestry / pivotal / underscore / showcasing / fostering / testament / landscape）？
27. serves as / boasts / features 该用 is 的地方？
28. 结尾升华（marks a new chapter / a testament to…）？
29. 名词化堆积（in order to / the implementation of X / utilize / offers、provides
    该用 has、gives 的地方）？

## 交付前四问（gates 全清后最后过一遍）

- 读者是谁？他读完第一句就知道跟他有什么关系吗？
- 每个判断都能追溯到事实、例子或明确来源吗？
- 文里的代号、缩写（尤其对话中自然长成的内部叫法）首现时，缺上下文的读者能懂吗？懂不了就展开一次。
- 朗读一遍：有没有哪句你不像会对同事说出口的？有就重写那句。
