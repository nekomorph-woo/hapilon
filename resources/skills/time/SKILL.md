# 时间

## 默认：当前时间

获取现在的时间只有一个入口，跑脚本拿系统输出：

```
node now.js
```

在本技能目录下执行。输出一行：本地时间（毫秒精度 ISO 格式）+ UTC 偏移 + 时区名，例如 `2026-02-14T12:34:56.789+08:00 Asia/Shanghai`。回答用户时直接引用这一行，不改写数值。

## 其他时间需求

时区换算、日期差值、时长累计、解析用户给的模糊时间等，不要自己算，用 `hapi -p` 写临时脚本跑出结果再回答：

```
hapi -p "把下面的时间需求写成一个临时脚本（node 或 bash），执行它，把输出原样返回：(<一句说清要算什么>)"
```

## 护栏

- 模型没有当前时间：任何「现在几点」「今天几号」都必须来自 now.js 的输出，禁止凭训练记忆、会话开头信息或上下文推测。
- 毫秒、UTC 偏移、时区名都必须来自系统输出，禁止心算偏移量或推算日期。
